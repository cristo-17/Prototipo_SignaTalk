# Evidencia en clase LAB 11 - Commit 06

## Proyecto
SIGNATALK - Sistema de reconocimiento de movimientos y voz con IA.

## Objetivo
Demostrar en clase el uso práctico de Git como herramienta de control de versiones.

## Actividad realizada
Se creó un archivo documental de evidencia, se agregó al área de preparación, se registró mediante commit y se subió al repositorio remoto en GitHub.

## Comandos utilizados
- git status
- git add
- git commit
- git push

## Importancia
Este commit permite evidenciar que el equipo puede registrar nuevos cambios, mantener trazabilidad y actualizar el repositorio remoto.
